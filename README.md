# dsh-davinci-qing

> **让青青住进你的dsh** —— 为创作者打造的 DaVinci Resolve Studio 深度工作流自动化引擎。

---

## 为什么做这个项目

在日常的商业拍摄与高强度后期制作中，真正消耗创作者心力的，往往不是审美判断与叙事决策本身，而是前期素材的分类归档、多机位轨道整理、基础还原节点挂载，以及反复核对导出参数这些高度重复的机械性劳动。

我们一直在思考：**如果 AI 不再只是停留在对话框里给出建议，而是真正理解时间线的结构、看懂调色节点树的逻辑，并安全地替你完成这些繁琐的前置工作，后期体验会发生怎样的改变？**

`dsh-davinci-qing` 正是为了解决这个问题而生。它通过底层 IPC 进程通信，将 DeepSeek Harness (DSH) 直接接入 **DaVinci Resolve Studio** 的媒体池、剪辑台、调色节点树、Fusion 合成与交付队列。你只需要用自然语言描述意图，它就能在你的工程里精准落地。

---

## 核心能力

### 1. 媒体池智能归档（Media Pool）
- **自动化素材整理**：扫描本地拍摄目录，按机位、日期或自定义规则自动建立素材箱（Bin）并完成入库。
- **元数据与子剪辑**：批量写入 Scene、Take 与关键词标签，大幅降低大型商业项目的检索成本。

### 2. 时间线精剪与标记同步（Edit & Markers）
- **多轨道精准编排**：支持新建指定规格的时间线，自动完成素材上轨、变换属性调整（缩放、裁切、动态缩放）与 SRT 字幕挂载。
- **审片与卡点标记**：根据音乐节拍或修改意见清单，在时间线指定帧位置批量生成带颜色与备注的 Marker。

### 3. 节点级调色与视觉闭环（Color Pipeline）
- **节点树与预设控制**：直接读取并操控片段的 Node Graph，支持按节点索引挂载 `.cube` 3D LUT、批量应用 `.drx` PowerGrade 预设，以及跨片段组复制调色方案。
- **实时帧截图审片**：支持导出当前播放头静帧供多模态视觉模型检视，实现“挂载基础还原 -> 截图核对曝光与肤色 -> 微调参数”的闭环工作流。

### 4. Fusion 与交付队列（Fusion & Deliver）
- **程序化图形生成**：向指定片段的 Fusion 合成中添加 `Text+` 等基础节点并批量写入文本内容。
- **渲染队列接管**：自动匹配团队渲染预设、配置输出路径与命名规则，一键推入 Render Queue。

## 安全机制：工程安全永远是第一位的

在真实商业项目中，任何不可逆的工程误操作都是灾难性的。`dsh-davinci-qing` 在底层内置了双重安全护栏：

1. **自动工程保存与时间线快照（Checkpoint）**：在执行任何批量删改时间线、覆盖节点调色或批量修改属性前，系统会强制触发工程保存，并自动克隆一条带时间戳的备份时间线（`[Backup_HHMMSS]_原时间线名`）。即使对 AI 的调整不满意，也能在 1 秒内切回原版。
2. **Pre-flight 参数预检**：在向达芬奇发送指令前，自动校验轨道索引合法性、LUT/DRX 本地路径有效性以及轨道锁定状态，从源头拦截异常崩溃。

## 环境前置要求

在开始部署前，请确保你的工作站满足以下条件：

- **软件版本**：**DaVinci Resolve Studio**（v18.5 / v19 / v20 / v21 及以上版本）。
  > *注：受限于 Blackmagic Design 官方接口策略，免费版 DaVinci Resolve 不支持外部脚本进程通信，必须使用 Studio 版本。*
- **运行环境**：Python 3.10 或更高版本。
- **开启外部脚本权限**：
  1. 打开 DaVinci Resolve Studio，进入左上角菜单 `DaVinci Resolve` -> `偏好设置 (Preferences)`。
  2. 切换到 `系统 (System)` -> `常规 (General)`。
  3. 将 `外部脚本使用 (External scripting using)` 设置为 **`本地 (Local)`**，点击保存并重启达芬奇。

## 快速开始

### 1. 克隆仓库并安装依赖
```bash
git clone [https://github.com/MokoKing666/dsh-davinci-qing.git](https://github.com/MokoKing666/dsh-davinci-qing.git)
cd dsh-davinci-qing
pip install -r requirements.txt
```

### 2. 运行环境自检
确保 DaVinci Resolve Studio 处于运行状态并已打开任意工程，执行自检脚本验证 IPC 链路：
```bash
python check_env.py
```
当终端输出 `Resolve Studio IPC Connected` 时，说明桥梁已成功打通。

### 3. 接入 DSH
将本项目目录下的 `SKILL.md` 及 MCP 服务配置注册至你的 DeepSeek Harness 技能目录中，重启 DSH 即可唤醒青青。

## 典型工作流示例

在 DSH 中，你可以直接向它发出如下指令：

- **前期素材整备**
  > “扫描 `D:\Shoot\2026_Commercial\A_Cam` 下的所有视频，在媒体池建立 `A机位_原片` 素材箱并导入，然后按拍摄顺序创建一条 4K 25fps 的粗剪时间线。”
- **一键挂载基础还原节点**
  > “先备份当前时间线。然后把 `D:\LUTs\SLog3_to_2383.cube` 挂载到当前时间线所有片段的第 2 个节点上，并在第 1 个节点预留曝光调整位。”
- **审片修改意见自动打点**
  > “根据这份客户修改清单，在时间线对应的时间码位置添加红色 Marker，并把具体修改要求写进 Marker 备注里。”
- **画面自检与交付**
  > “截取当前播放头这一帧的画面，帮我看看人物面部高光有没有溢出；确认没问题后，用 `H265_Master_4K` 预设添加到渲染队列。”
